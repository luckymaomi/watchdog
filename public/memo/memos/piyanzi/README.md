# 屁眼子 Skill 合集

Agent 业务操作说明合集（备忘录形态，不是 `.agents/skills/`）。页面分类筛「屁眼子」可见本合集条目。

## 目录结构

文件夹序号只给仓库排目录用；**对主人说话、Skill 正文里只用 Skill 名，不报文件夹号。**

```
memos/piyanzi/
├── README.md      ← 本说明（给人浏览仓库用）
├── MEMO.md        ← 合集入口：唤醒词、拼装规则、名称索引（不抄能力正文）
├── 001/MEMO.md    ← 检查单手册比对填写（报装 + 综述 + 细则）
└── 002/MEMO.md    ← 副驾驶流转更新（报装 + 综述 + 细则）
```

## 单源维护

| 段落 | 写在哪 | 用途 |
| --- | --- | --- |
| **报装** | 各 Skill 的 `MEMO.md` | 合集「能做什么」时按入口表顺序拼装；改能力只改这里 |
| **综述** | 各 Skill 的 `MEMO.md` | `启动` 该 Skill 时的开场与执行入口 |
| 入口 `MEMO.md` | 只索引 + 拼装规则 | **禁止**复制报装/综述正文 |

## 怎么喊

- 对话出现 `屁眼子` → 先「主人，小的已就位」，再问这轮要哪套 / 缺什么
- `屁眼子，我们能做什么` / `屁眼子，你能做什么` → 就位开场 + 依次读各 Skill「报装」拼装
- `屁眼子，启动检查单手册比对填写` → 打开对应 Skill「综述」并执行
- 对主人回复一律纯 txt（可复制）；可用 `1` `2` `3` `4` 分行，不要 markdown 列表或加粗
