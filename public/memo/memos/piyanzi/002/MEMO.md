## 这张表是干什么的

副驾驶积分表维护货航 **777 副驾驶**从进货航到可流转的进度与积分，核心是「总表」。名单、技术等级获得日、报务获得日从实力表 / 技术等级表 / 资质表取数，总表用公式汇总。路径以用户当次引用为准。

---

## 业务规则（从总表公式反推）

### 技术等级路径

学员 → A1 → A2 → B → C → D。A1 为进货航、本表追踪起点。

### 考核项目（H 列）——下一步考什么

| 条件 | 显示 |
|------|------|
| 已有 B | **不考核**（主路径考核结束） |
| 尚无 B、已有 A2 | 下一步考 **B** |
| 尚无 A2、已有 A1 | 下一步考 **A2** |
| 尚无 A1 | **学员** |

### 进度预警（I 列）——时限

| 条件 | 结果 |
|------|------|
| 已有 B | 显示「完成考核」 |
| 已有 A2、未到 B | **A2 日期 + 390 天**（约 13 个月）内应拿到 B |
| 已有 A1、未到 A2 | **A1 日期 + 120 天**（约 4 个月）内应拿到 A2 |

该列为日期格式；格式不对会显示成 `46357` 这类序列号。

### 怎样才算「可流转」（G 列）

须**同时**满足（培训状态才显示「可流转」，否则「继续培训」）：

1. **总分 Z ≥ 1000**
2. **已有 C 类**技术等级
3. **已有欧洲报务**
4. **已有美加报务**（西亚报务不计流转门槛，只计分）
5. **本机型飞行月数**（自 A1 起）**> 48** 个月
6. **C 类运行月数 > 3** 个月

积分排名（F）也只对**已有 C** 的人做 `RANK`。

### 总分怎么凑（Z 列实际相加项）

与「计算说明」12 项对应；Z 公式为：

`AB+AD+AF+AI+AK+AN+AQ+AT+AX+AY+AZ+AV`

| 部分 | 规则 | 对应列 |
|------|------|--------|
| 改装理论/模拟机/本场一次通过 | 是→5 / 10 / 5 | AB / AD / AF |
| B 类运行 | 每满 1 月 ×3 | AI（AH 为月数） |
| C 类运行 | 每满 1 月 ×6 | AK |
| 欧洲/美加/西亚报务 | **仅按月** ×6，到手不加固定 10 分 | AN / AQ / AT |
| 飞行经历 | 有 C 后：总经历时间 ×0.1 | AV |
| 年资、扣分、加分 | 手填或查「加分」表 | AX / AY / AZ |

表中 AL/AO/AR（报务到手 10 分）、AG（技术等级个数分）即使有公式，**也不进总分 Z**，可忽略。

## 必须守住的维护规则

1. **只算货航这段。** 人成为 **777 的 A1 类副驾驶**，才是本表追踪起点。A1 之前在外单位拿的等级、报务一律不算。
2. **报务取法。** 欧洲 EEUO、美加 EAMA、西亚 EWAS：只认生效日**晚于该人 A1** 的段；若还有多段，取其中**最早**一段；没有则留空。
3. **这些人不要进总表，不参与排名。**
   - E 类副驾驶
   - 原单位含「新疆」的（含「新疆分公司」「新疆分公司（借调）」等）
   - 薛京亮（210531）、刘信（212982）
   - 清洗表里留不留无所谓，**总表不要出现他们**
4. **日期空了不能写成坑公式的空文本。** 判断有没有日期用 `N(单元格)>0`；等级个数用 `COUNT`，不用 `COUNTA`。

## 常见坑

1. **`""` 不是空白。** 日期公式返回空文本时，若写 `L2>0` 会 `#VALUE!`。一律 `N(L2)>0`。
2. **`COUNTA` 会把 `""` 算进去。** 等级分用 `COUNT(L,O,R,S)`。
3. **删人后公式行号错位。** 删完必须按**当前行号**重写所有含行号的公式；日期列须是 `VLOOKUP(A本行,…)`，总分须是 `AB本行+…`。
4. **改人数后必须改 RANK 范围。** 所有行的 `F` 都要是 `RANK(Z本行,Z$2:Z$末行)`。末行变了只改一行不够。
5. **经历时间查不到会毒死总分和排名。** `AU` 必须带 `IFERROR(...,0)`。
6. **考核项目不要用 `NA()` 收尾。** 用 `""`。
7. **等级倒序。** 车有路 A1 固定用更早的 **2020-07-04**，不要用 2024-10-31（否则晚于 A2）。
8. **资质表只用 Sheet0。** Sheet1 与 Sheet0 重复。
9. **补人/重写公式后必须刷数字格式。** 只写公式不复制格式时，后面新行会是「常规」。进度预警（I）公式是 `A2日期+120` 或 `A2日期+390`，结果是日期序列号；格式不对就会显示成 `46357` 而不是日期。总分 Z、技术等级分 AG、经历时间 AU/AV 等也会丢小数/会计格式。**以第 2 行为准，把各列 `number_format` 刷到所有数据行**（或格式刷整行）。删人、加人、批量改公式后都要做这一步。
