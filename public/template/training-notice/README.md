# B777 转机型理论培训开课通知模板

本目录保存机长、副驾驶两份开课通知 Word 模板。模板使用 `{字段名}` 占位符，B777 机型、参训地点、其他事项正文、段落样式、字体、字号及页面设置沿用原文件。两份模板的岗位字段分别填写机长、副驾驶。

| 字段 | 填写内容 |
| --- | --- |
| `{年份}` | 通知标题年份，如 `2027`；不带“年” |
| `{期数}` | 期数，如 `一`；不带“第”“期” |
| `{岗位}` | `机长`或`副驾驶`；标题与正文共用 |
| `{主送单位}` | 通知抬头单位；不带冒号 |
| `{开课日期}` | 正文开课日期，如 `2027年3月1日`；不带“起” |
| `{人数}` | 参训人数，如 `2`；不带“名” |
| `{班级编号}` | 完整班级编号 |
| `{参训单位}` | 参训人员段落中的单位；不带冒号 |
| `{参训人员}` | 姓名与员工号组成的名单，如 `示例甲(000001)、示例乙(000002)`；不带末尾句号 |
| `{学习开始日期}` | 理论学习开始日期，如 `2027年3月1日` |
| `{学习结束日期}` | 理论学习结束日期，如 `2027年3月23日` |
| `{落款单位}` | 通知署名单位，原文件为`南货航飞行部` |
| `{发文日期}` | 落款日期，如 `2027年2月25日` |

日期字段填写完整日期，起止之间的“至”由模板保留。开课日期与学习开始日期使用各自字段，填写时核对一致性；人数应与名单人数一致。参训人员目前为整段文本字段，未加入循环语法。

模板未接入页面或自动生成流程，目录内不保存原始通知和真实参训名单。占位符文字长度及后续实际内容长度可能影响 Word 自动换行，模板不调整原有排版参数。
