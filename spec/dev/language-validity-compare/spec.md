# 英语汉语有效期比对开发规格

## 输入与解析

- 浏览器本地读取两份 `.xls` 或 `.xlsx` 文件，通过表头定位工作表，不依赖文件名、sheet 名或固定行。
- 人员信息表要求包含“员工号”“姓名”“英语能力”“汉语能力”；能力值保留原文，明确日期统一为 `YYYY-MM-DD`。
- 局方数据表要求包含“飞行员ID”“姓名”“执照备注”；从“执照备注”（样本为 AK 列）按语言行提取“有效期至”后的日期。
- 两侧编号体系不同，按归一化姓名匹配；编号、姓名、来源行号均保留用于复核。重复姓名只使用首条记录并记录问题。
- “不适用”“待确认”等非日期文本不得推断为日期；无法识别的非空日期文本记录问题。

## 比对与输出

- 每名人员分别生成英语、汉语明细。两侧明确日期相同为“双方一致”，日期不同为“日期不一致”；单侧有明确日期为“仅人员信息”或“仅局方数据”；两侧均无明确日期为“均无有效期”。未匹配人员状态为“人员未匹配”或“局方未匹配”。
- 页面默认展示需关注状态，可按语言和状态筛选；摘要展示两侧人数、姓名匹配人数、需关注项和数据问题。
- 导出“语言汇总”“比对明细”“数据问题”三个工作表，包含原始值、归一日期、来源位置、状态和问题说明，冻结首行并启用筛选。
- 文件只在浏览器本地处理，不修改上传源文件。
