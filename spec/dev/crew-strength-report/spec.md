# 实力周报开发规格

## 产品边界

`crew-strength-report` 在浏览器本地读取一份或多份飞行实力表，生成当前人员结构、带队资格和跨期变化图，用于周报编制与数据复核。工具只做汇总，不修改原始文件，不保存人员明细，也不向服务器上传数据。

## 输入与工作表识别

- 支持 `.xlsx`、`.xls`，文件选择器允许多选，拖放区允许继续追加；应用不设置文件数量上限，实际容量受浏览器可用内存限制。
- 不依赖文件名、固定 sheet 名或固定列号。每个工作簿按 sheet 顺序查找前 20 行，选择首个同时含“技术信息”“是否运行”“RAMA”“REUO”表头的 sheet。
- 表头前允许有说明行，表头文字读取后去除首尾空格；表头以下的非空行是数据行。
- 找不到完整表头的文件独立报错，不影响同批其他文件。
- 文件名包含有效的 `YYYYMMDD` 八位日期（年份以 `20` 开头）时，图表快照标签显示为 `YYYY-MM-DD`；否则显示去掉扩展名的文件名。

## 统计口径

- 只有“是否运行”去除首尾空格后精确等于“是”的行进入全部指标；“否”、空白和其他值均排除。
- 技术信息按文字分类，匹配顺序为教员、副驾驶、机长：包含“飞行教员”或“教员”计入教员，包含“副驾驶”计入副驾驶，包含“机长”计入机长。
- 无法归入上述三类的运行人员仍计入运行人数，但不进入技术信息饼图，并显示未识别人数提示。
- RAMA 有值计入北美带队，REUO 有值计入欧洲带队；空值以及 `0`、`否`、`无`、`不适用`、`false`、`no` 不算有资格，匹配不区分英文大小写。
- 运行人数与教员、机长、副驾驶、技术信息未识别人数满足闭合关系。

## 多文件状态与变化

- 页面内有序快照数组是唯一比较顺序；新文件追加到末尾，用户可拖动卡片或用上下按钮调整顺序。
- 排序后的最后一份文件是当前快照，驱动摘要、技术信息饼图和带队资格柱状图。
- 多期变化图横轴严格按文件卡片顺序显示，支持柱状图和折线图切换。
- 可选指标为运行人员、教员、机长、副驾驶、北美带队、欧洲带队。
- 一份文件时默认勾选全部指标；两份以上文件时，某指标在所有快照中存在两个以上不同数值即视为有变化，默认只勾选这些指标。只调整顺序不重置人工选择；新增或移除文件后按剩余数据重新应用默认选择。

## 输出契约

- 技术信息以一个饼图展示教员、机长、副驾驶；带队资格以一个柱状图展示北美带队和欧洲带队。
- 图表使用本地 ECharts 和低饱和领域色，文字、背景、边框、网格及明暗主题从共享主题 token 读取。
- 每个 ECharts 图右上角可单独保存图片；“导出周报 PNG”使用本地 html2canvas 导出当前报告区域。
- “导出统计 Excel”包含 `快照统计` 和 `相邻变化` 两个 sheet。快照统计按当前文件顺序输出来源、统计值和未识别数；相邻变化输出相邻两份快照的数值差。
