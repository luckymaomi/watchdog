# 工具首页开发规格

工具首页统一展示公开工具入口，并通过“全部、重型、轻型、自动化”筛选工具，默认显示“全部”。

`src/tool/tools-data.ts` 是首页工具内容和独立应用导出的唯一清单，保存名称、说明、入口、发布状态、分类、可选的 `homepageState` 和可选的 `homepageVisibility`。清单中的工具全部进入独立 ZIP 构建；首页默认不渲染隐藏工具，解锁彩蛋后将其直接并入原工具网格，不维护独立白名单或固定数量。

“菜鸟教程”固定为工具清单第一项，以 Beta 状态展示面向南货航新员工的技术等级、教员考试员、资质和重新获得资格知识；教程正文与 `spec/user` 中保留的用户手册文档分开维护，首页入口默认隐藏。

首页直接显示顶部导航、搜索、分类和工具索引，不设置屏保或门禁。顶栏提供备忘录、喂鱼模式开关和白天/暗夜模式切换，不发布用户手册或 GitHub 入口；首次访问默认白天模式，选择通过共享主题设置保存在浏览器本地。首页始终开启 Riverscape 动态水族箱背景（`public/tool/habitats/`，iframe 隔离嵌入），平时背景层 `pointer-events: none`，不得拦截搜索、分类、卡片或下载点击。顶栏「喂鱼」按钮进入喂鱼模式后：隐藏整个工具首页外壳（含顶栏其余入口与主内容），仅保留半透明「停止喂鱼」浮动按钮；背景层改为可交互，支持移动指针与鱼互动，以及点击水面投喂。再次点击退出喂鱼模式，恢复工具首页。喂鱼模式仅会话内有效，刷新后回到普通工具首页。WebGL 不可用或加载失败时首页仍须可用。顶栏的 `csn2api` 外链默认隐藏，解锁彩蛋后与隐藏工具同时显示，并跳转至 `https://luckymaomi.github.io/csn2api`。主内容不增加宣传 Hero。

页面使用全站共享的柔和野兽派视觉：透明页面底板让水族箱背景可见，内容区使用高透明度表面（约 85%～95% 主题表面混合）保持文字与控件可读；方角完整边框、无模糊硬阴影、低饱和多色点缀和轻量位移反馈。颜色、边框、阴影、状态和主题值由 `public/theme.css` 统一提供，首页 CSS 只维护首页布局、背景层定位、透明化特判和组件特判；不使用渐变噪音、严重模糊、单边强调条或吉祥物。桌面工具索引每行五项，窄屏依次降为四栏、三栏、双栏和单栏。每项显示工具名称、用途摘要、状态小字、只读开关和 Bootstrap 风格下载图标，不显示文字导出按钮。水族箱背景仅作用于工具首页，不作用于具体工具页面。

`homepageState` 只有 `enabled`、`beta`、`cooling` 三种状态。未填写或为 `enabled` 时显示“已启用”，`beta` 显示“Beta 测试”，内部 `cooling` 标识显示“已弃用”。`homepageVisibility: "hidden"` 与 `cooling` 状态都让工具默认不在首页渲染，不改变原 `category`；解锁后，公开工具保持在上方网格，隐藏工具另起下方网格，两组之间只保留空白间距，并与其他工具一起接受分类按钮和搜索筛选。当前默认隐藏“菜鸟教程”“培训皇帝”“换季学习”“审计之王”“姓名匹配员工号”“航线班次统计”“实力周报”“Word 模板填充器”“PDF 工具”“PDF 加水印”“图片工具”“文本拼接助手”“人员结构统计”“运行资质比对”“英语汉语有效期比对”“国际航班资质反推”“锁班乞丐”“飞行经历查询（乞丐版）”“珠海皇帝”和“自动点 OA 助手”。四个已弃用工具整张卡片使用灰色表面并保持可点击，不增加删除线或独立区域样式。

搜索框和分类按钮高度统一为 44px。顶栏在“备忘录”左侧保留一个与顶栏按钮同高的 40px 正方形输入区域，仅显示中性边框和表面色；该区域不显示 placeholder、输入值、光标或选中效果。输入 `unlock` 后连续点击“全部”按钮 3 次，每两次相邻点击间隔不超过 700ms 时，在当前页面内存中显示默认隐藏工具。口令输入本身不计入点击时间，点击其他按钮不参与解锁。刷新页面后恢复隐藏。该彩蛋不提供安全防护，工具固定 URL 和构建产物始终可访问。

生产构建在 `dist/exports/` 中按工具 `entry` 逐项生成 ZIP，数量始终等于当前工具清单数量。每个 ZIP 根目录包含 `index.html`、独立应用脚本、离线运行时、主题和页面实际需要的库、模板、Worker、JSON、Python 文件及依赖说明；不包含其他工具、`__pycache__`、`.pyc`、source map 或仓库开发文件。导出脚本使用 IIFE，并由离线运行时承接 `file://` 下的本地 `fetch()` 和 Worker 资源，因此解压后可直接打开根 `index.html`。新增工具只需按既有规则加入工具清单和页面构建入口，导出数量随清单自动变化。

搜索按工具名称、说明和分类文字筛选当前分类，结果数量随筛选更新。没有匹配项时显示统一空状态。
