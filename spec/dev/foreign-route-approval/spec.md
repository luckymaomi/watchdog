# 外籍航线批复录入

工具入口 `foreign-route-approval`，静态浏览器本地处理。业务依据为同级 piyanzi 仓库的 `core/waiji-daifei-pifu-hebing.md`，辅助脚本 `scripts/waiji_daifei_merge.py` 用于独立基准核验。

## 输入与检查

分别上传开放部分、临开部分 Excel（xlsx/xls），每份选择一张工作表。开放表在前 20 行识别包含公司、去程的表头，再映射序号、公司、两航站、去程、回程、台湾飞行员字段；航站支持同名双列或航站A/航站B。台湾字段表头忽略换行和空白。临开无表头时按这七列顺序读取，允许单单元格批复标题，也允许第一行直接为数据。空行跳过，记录文件名、工作表和 Excel 行号。

公司、两航站、去程为空，缺少必要表头、Excel 错误单元格、文本字段为日期、空工作表均报告错误并禁止导出。台湾值去除首尾空白后照抄，空值作“否”；航路码保留内部换行。不会默认为缺失公司补 CSG。用户必须明确填写合法生效和失效日期，失效不得早于生效；预检可先查看数据，但日期不完整不可导出。可选航季标签从文件名中的四位年份与夏秋/冬春提取，也可手动填写，不从航季推断日期。

## 合并与展开

开放行在前，临开行在后，保持原顺序及重复行，序号重编。导出合并表只有原七列，不增加来源字段。

复制原模板位于 `public/template/foreign-route-approval/approval-template.xlsx`，SHA256 为 `02f8ad76ffffe13eab1c8e9fb28bd959535c461605d82a323d389fc68ee4e80d`。模板机场列表 A:B 中的中文名数字尾号分组，按数字升序；一个编号变体也视为展开。只有与基地名完全相同才展开，单机场精确名不改写；A、B 两侧做笛卡尔积。

去程每组合生成 A→B；源回程非空才生成 B→A。每行均挂原航路码，因机场列表展开的行以蓝字显示。未知机场按原 skill 预检警告，保留原值与公式，不私改名称或代码；如“上海/浦东”是模板精确名，“上海”“浦东”不能自动视为同名。

## 导出

结果保留开放与临开合并、去程、回程、机场列表、俄罗斯机场列表五表。使用 JSZip 修改原模板前三张表的数据区、追加字体边框和日期样式、设置打开时重算。两张查询表及其余未修改 ZIP 部件原样保留；表头、列宽、分页配置继承模板，筛选范围和维度随结果更新。

去程/回程共 12 列，按照模板表头，不交换回程表头文本。PORTA、PORTB 公式分别为 `VLOOKUP(C行,机场列表!A:B,2,FALSE)` 和 D 列对应公式；俄罗斯公式为 `VLOOKUP(E行,俄罗斯机场列表!A:C,3,FALSE)` 和 F 列对应公式。日期写 Excel 1900 序列，显示格式 `YYYY-MM-DD`。不在浏览器计算公式缓存，需在 Excel 中打开重算。俄罗斯列表只含俄罗斯机场，未匹配时返回 `#N/A`，不私自改成“否”。

文件名遵循 skill：`{航季}外籍带飞开放临开合并（由皮燕子合并去程回程生效YYYY-MM-DD至YYYY-MM-DD）.xlsx`，航季标签中的 Windows 非法文件名字符替换为下划线。原件与原模板只读，结果另存。

## 页面与状态

上传、日期操作、结果摘要、问题和可切换明细分别展示。预览来源只显示在页面。文件、工作表、日期或航季变化立即使旧结果失效；文件读取用各自版本号，模板加载用独立请求号；导出使用状态快照，配置变更后旧导出不会触发下载。模板失败可重试，导出失败可重试。接入全站共享主题和自动独立工具包，模板引用同时用于模板下载与 fetch 内嵌。

## 验证边界

核心测试从 src 导入，验证解析、顺序、笛卡尔积、空回程、台湾值、异常、日期、导出公式、样式与查询表字节保留。独立原脚本回放对三表逐格、逐行校验，不以集合比较代替序列比较。真实输入、基准与过程文件不提交。页面视觉由 owner 人工判断。
