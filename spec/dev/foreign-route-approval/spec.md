# 外籍航线批复录入

工具入口 `foreign-route-approval`，静态浏览器本地处理。业务依据为同级 piyanzi 仓库的 `core/waiji-daifei-pifu-hebing.md`；skill 记录业务原理，不附固定 Python 执行脚本。

## 输入与检查

航司范围由 owner 根据数据室反馈确认：货航为 CSG。APP 默认仅勾选 CSG；根据当前两张所选工作表列出各航司及开放/临开条数，支持勾选一个或多个航司。CSG 不在表中时仍显示零条，不自动切到其他航司。代码去首尾空白、转大写后按完整代码匹配，CSGX 不等于 CSG；导出保留源公司文本。未选航司或所选航司无记录时报告错误并禁止导出。

分别上传开放部分、临开部分 Excel（xlsx/xls），每份选择一张工作表。开放表在前 20 行识别包含公司、去程的表头，再映射序号、公司、两航站、去程、回程、台湾飞行员字段；公司支持“公司”“航空公司”，表头换行与空白忽略；航站支持同名双列或航站A/航站B。临开无表头时按这七列顺序读取，允许单单元格批复标题，也允许第一行直接为数据。空行跳过；仅序号列有以“执行日期”“相关要求”“说明”“备注”加冒号或空白开头的文字，其余六字段均空且无错误单元格时按说明行跳过。序号数字占位行、无法识别的文字行和缺公司/航站的不完整行仍报告错误。说明行中的日期不自动填写页面日期。记录文件名、工作表和 Excel 行号。

缺少必要表头、公司缺失或错误等归属不明、空工作表均报告错误并禁止导出。行内错误保留航司及来源位置，单行坏值不截断后续数据；未选航司的行内错误不影响已选范围，所选航司的两航站为空、Excel 错误单元格、文本字段为日期仍阻止导出。不会默认为缺失公司补 CSG。台湾值去除首尾空白后照抄，空值作“否”。去程、回程只按空白或非空白决定是否生成方向；读取时去首尾空白，内部编号、逗号、换行整段保留，不拆分、不做格式或内容判断。空单元格、空字符串、纯空白字符都视为空白，不是必填错误。用户必须明确填写合法生效和失效日期，失效不得早于生效；预检可先查看数据，但日期不完整不可导出。可选航季标签从文件名中的四位年份与夏秋/冬春提取，也可手动填写，不从航季推断日期。

## 合并与展开

先筛选已选航司，再开放行在前、临开行在后合并，保持所选范围内的原顺序及重复行，序号重编。机场警告、空方向统计和多机场展开均仅针对所选范围。摘要分别显示航司、源表开放/临开数量、排除其他航司数量及筛选后开放/临开数量。导出三张结果表仅含所选范围，合并表只有原七列，不增加来源字段。

复制原模板位于 `public/template/foreign-route-approval/approval-template.xlsx`，SHA256 为 `7937b14bdba56d7d99a61ac910d9e74b71525f7fca844a72569532ae17a0fb36`。模板机场列表 A:B 中的中文名数字尾号分组，按数字升序；一个编号变体也视为展开。只有与基地名完全相同才展开，单机场精确名不改写；A、B 两侧做笛卡尔积。

航站A、航站B是航线两端的始发／目的地机场，不是同一机场的不同航站楼。按 owner 确认，模板 A:B 精确收录「墨西哥城空运机场 → NLU（费利佩·安赫莱斯国际机场）」「墨西哥城国际 → MEX（贝尼托·胡亚雷斯国际机场）」。这两个明确机场名不展开、不改源名；仅基地名「墨西哥城」仍展开为原有「墨西哥城1 → MEX」「墨西哥城2 → NLU」。APP 解析、下载模板和导出查询表均使用同一模板，与 piyanzi 模板字节一致。

两方向独立判断：源去程非空才生成 A→B；源回程非空才生成 B→A。两方向都非空出双向，仅一个非空只出该方向；双向均空保留合并 OD、显示来源提示，不生成方向行。摘要分别统计去程空、回程空跳过的源 OD 条数。每个有值方向的展开行均挂原航路字符串，因机场列表展开的行以蓝字显示；方向源空白与展开后漏挂码是不同语义。未知机场按原 skill 预检警告，保留原值与公式，不私改名称或代码；如“上海/浦东”是模板精确名，“上海”“浦东”不能自动视为同名。

## 导出

结果保留开放与临开合并、去程、回程、机场列表、俄罗斯机场列表五表。使用 JSZip 修改原模板前三张表的数据区、追加字体边框和日期样式、设置打开时重算。两张查询表及其余未修改 ZIP 部件原样保留；表头、列宽、分页配置继承模板，筛选范围和维度随结果更新。

去程/回程共 12 列，按照模板表头，不交换回程表头文本。航站A/B保留原 OD 端点身份：去程为原A→原B，回程为原B→原A；PORT 两列始终是本行起飞、落地机场代码。因此回程“录入PORT_A”查原B，“录入PORT_B”查原A。这与原夏秋合并表和模板一致，逻辑正确，沿用历史命名，不因表头字母再交换代码。PORTA、PORTB 公式分别为 `VLOOKUP(C行,机场列表!A:B,2,FALSE)` 和 D 列对应公式；俄罗斯公式为 `VLOOKUP(E行,俄罗斯机场列表!A:C,3,FALSE)` 和 F 列对应公式。日期写 Excel 1900 序列，显示格式 `YYYY-MM-DD`。不在浏览器计算公式缓存，需在 Excel 中打开重算。俄罗斯列表只含俄罗斯机场，未匹配时返回 `#N/A`，不私自改成“否”。

文件名遵循 skill：`{航季}外籍带飞开放临开合并（由皮燕子合并去程回程生效YYYY-MM-DD至YYYY-MM-DD）.xlsx`，航季标签中的 Windows 非法文件名字符替换为下划线。原件与原模板只读，结果另存。

## 页面与状态

上传、航司勾选、日期操作、结果摘要、问题和可切换明细分别展示。上传区标题旁提供“下载录入 Excel 模板”按钮，无需上传文件即可下载三张空数据表与两张机场查询表；说明模板用途并区分上传的原始批复。预览来源只显示在页面。文件、工作表、航司勾选、日期或航季变化立即使旧结果失效；文件读取用各自版本号，模板加载用独立请求号；导出使用状态快照，配置变更后旧导出不会触发下载。更换输入后移除已不在列表内的勾选，CSG始终作为可选项保留；不会自动全选或替换为其他航司。模板失败可重试，导出失败可重试。接入全站共享主题和自动独立工具包，模板引用同时用于模板下载与 fetch 内嵌。

## 验证边界

核心测试从 src 导入，验证默认CSG、单选/多选、空选/无匹配、范围内校验、表头别名、解析、顺序、笛卡尔积、四种方向空白组合、任意非空航路文本完整保留、台湾值、异常、日期、导出公式、样式与查询表字节保留。按 skill 原理在相同航司范围内从原始输入独立计算期望序列，对三表逐格、逐行校验，保留顺序、重复次数和完整航路，不以集合比较代替序列比较。真实输入、基准与过程文件不提交。页面视觉由 owner 人工判断。
