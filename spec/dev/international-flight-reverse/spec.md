# 国际航班资质反推开发规格

## 产品边界

工具在浏览器本地读取航班明细表和临期资质表，按员工所属地区与机场三字码查找反推日期前的最近航班，展示近期航班并生成核对用 Excel。工具不连接飞行门户、不修改资质系统、不写回原始文件。

## 输入契约

页面提供动态 Excel 模板下载，模板包含“临期资质表”“机场三字代码”“填写说明”三个工作表；模板字段与解析器按表头识别规则一致。

- 航班明细表按表头识别“员工号”“日期”“离场”“到达”；可选读取“姓名”“航班号”“飞行阶段”。
- 临期资质表按表头识别“员工号”“姓名”“资质”“反推日期”；为兼容旧表，也接受“地区”或“区域”作为资质列名。
- 临期资质表的“资质”字段按包含关键字归一：包含“北美”归一为“北美”，包含“西亚”归一为“西亚”，包含“欧洲”归一为“欧洲”，包含“东南亚”归一为“东南亚”；未命中这些关键字的文本保留原值。
- 临期资质表工作簿可包含地区机场配置表，表头为“地区”和“机场三字代码”（或“机场代码”“三字码”）；没有配置表时使用页面默认配置。
- 员工号在读取边界归一为数字文本，日期归一为 `YYYY-MM-DD`；无法归一的行进入数据问题。

## 统计规则

- 仅保留航班日期小于等于员工反推日期的记录。
- 默认离场和到达任一方向命中地区机场代码即视为命中；页面可分别关闭离场或到达匹配。
- 同一航班阶段会拆成多行，去重键为员工号、日期、航班号、离场和到达；航班号为空时使用来源行保证不误合并。
- 去重后按日期倒序、来源行倒序排列，取页面参数“近期航班数”条；默认值为 3，不作为业务常量写死。
- 最近航班日期用于建议有效期：按最近航班所在月份加资质年限、减重叠月数，截止日固定取目标月的最后一天，不受最近航班具体日号影响。默认年限 1、重叠 0 个月，即最近航班月份加一年后取该周年月自然月末；例如最近航班为 `2026-11-06`，建议有效期为 `2027-11-30`。同年同月内其他航班同样算到该月底。年限和重叠月数仍可调整，页面不提供目标日期输入。
- 地区无机场配置、未找到匹配航班和完全重复的资质任务均在结果或数据问题中明确标识，不阻断其他任务；同一员工同一地区的不同资质分别保留。

## 输出契约

导出文件包含五个工作表：

- `最近航班汇总`：每个员工/资质任务的原始资质、归一地区、最近航班、建议有效期、命中机场和状态说明。
- `近期航班明细`：按序号列出每个任务的原始资质、归一地区、N 条航班、路线、命中机场、阶段和来源行。
- `机场近期航班`：按员工、资质和机场分别列出各机场最近 N 条航班，序号在每个员工/机场内独立计算。
- `机场配置`：本次使用的地区机场代码和分析参数，并注明有效期截止日为目标月自然月末。
- `数据问题`：解析、配置和分析过程中的异常及来源位置。

所有结果表冻结首行并启用筛选；原始文件只读。

## 文件职责

- `models.ts`：稳定数据模型和默认参数。
- `workbook.ts`：表头定位、日期/员工号/机场代码归一及 Excel 问题收集。
- `logic.ts`：机场匹配、阶段去重、最近 N 条和建议有效期纯函数。
- `export.ts`：五个工作表的导出结构。
- `view.ts`：页面状态和结果表格渲染。
- `main.ts`：文件上传、参数读取、分析和导出接线。

## 验证要求

测试覆盖日期截止、方向匹配、阶段去重、近期数量变化、有效期月底计算、表头别名、重复任务和导出工作表结构；完成后运行仓库全量 build、typecheck、test、verify。
