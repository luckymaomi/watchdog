# 培训签到表

## CRM

1. 打开“培训签到表”，等待默认花名册和 CRM 模板加载完成。
2. 培训项目选择`CRM`。
3. 粘贴包含参训人员姓名的文字。
4. 填写培训期次、开始日期、结束日期、教员1、教员2和第二天教员3。
5. 核对人员预览和数据健康检查。
6. 点击“导出”。

导出的 ZIP 包含预订报名表、第一天签到表和第二天签到表。三份表使用同一名单和顺序。

三份 Excel 在原模板上填写，保留页眉图片、格式和打印设置。名单至少保留两行，人多时按原行样式向下增加。

报名表中的技术等级只写`机长`或`副驾驶`。飞行教员归为机长，机型固定为`777`，备注留空。第一天使用开始日期和教员1、教员2；第二天使用结束日期，并在相同两名教员后增加教员3。

需要使用其他花名册时，在高级选项中选择替换文件。工具不会修改默认花名册或内置模板。
