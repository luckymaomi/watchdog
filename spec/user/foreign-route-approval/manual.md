# 外籍航线批复录入

1. 从工具首页打开“外籍航线批复录入”。
2. 分别上传开放部分和临开部分 Excel，确认各自所选工作表。临开可没有表头，列序为序号、公司、航站、航站、去程、回程、是否有台湾地区飞行员。
3. 填写生效日期、失效日期。航季标签可选，用于结果文件名；日期不会自动推断。
4. 点击“预检并生成预览”，核对合并条数、去回程行数、去程空/回程空跳过数和多机场命中数；切换合并 OD、去程、回程查看明细及源行。
5. 有字段错误时修正原 Excel 并重新上传。未知机场会显示名称与来源行，请核对原模板“机场列表”的精确名称；工具保留原值，不擅自改码。
6. 点击“导出录入 Excel”，在 Excel 中打开结果以重算 PORT 和俄罗斯查询公式。两张机场查询表保留，俄罗斯列表未命中时为 `#N/A`，与原模板一致。

开放先临开后，不去重；公司表头也可写“航空公司”，允许表头换行。台湾飞行员空白按“否”。去程、回程各自有值才生成该方向，空白则跳过；双向都空保留合并记录并提示。航路字段只看空白/非空白，逗号、编号和换行整段保留。多机场组合的有值方向每行全挂航路码，展开行使用蓝字。原表末尾仅序号列填写的执行日期、要求等说明会跳过，不计入航线，也不会自动填写页面日期。原件不会被修改。页面右上角可下载内置原空模板。

文件或配置更改后需重新预检。处理完全在本机浏览器完成；导出独立工具包后解压打开 index.html 使用，包内包含模板。
