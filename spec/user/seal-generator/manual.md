# 印章生成器

打开工具箱中的“印章生成器”，填写单位名称；章名和编号没有就留空。修改会自动更新预览。

## 对着原图调整

1. 上传参考章图片，支持 PNG、JPG、WebP，最大 20 MB。
2. 在预览里拖动底图，用缩放、旋转把参考外圈对齐。把生成章不透明度拉到 0，可以只看原图。
3. 调圆圈大小和边框粗细，再调名称字体、字号、字宽、字距、离圆心距离与旋转。
4. 展开五角星设置，调整大小、角度及横纵位置。
5. 展开“章名与编号”，分别选字体和调整字号、字宽、字距及位置；编号可选弧形或横排。
6. 隐藏参考图查看最终章面，点击“下载透明 PNG”或“下载 SVG”。

滑块右侧的数字可以直接填写，样式没有人为上限，超过滑块范围时会自动扩展。例如名称字号可以填 100、150；文字不会自动缩小，也不会自动往圆圈内收。超出预览画布的部分会被裁掉，可按原图自行调整。“底图回正”恢复参考图位置、缩放、旋转和不透明度；“恢复印章默认样式”保留已填文字，重置生成章样式。

## 字体与下载

内置朱雀仿宋、霞鹜文楷、思源宋体、思源黑体、站酷小薇，可以先用仿宋对照细长的章面文字，编号另选黑体。仅凭图片不能保证识别出原字体，需要查看字形并调整字宽。也可选本机宋体、仿宋、黑体、楷体，但本机没有对应字体时会替代显示。

内置字体第一次使用需要加载；加载失败时换一种字体或重新操作。所有字库均随工具提供，不请求外部字体网站。SVG 保存选用的内置字库，文件会相对大一些；选本机字体时，SVG 换电脑可能变化。PNG 固定导出时的字形。

“导出尺寸”可设直径和 PNG 清晰度，默认 40 mm、300 DPI，只是可调默认值。PNG 写入像素密度；具体办公软件如何插入和打印仍需查看输出尺寸。

参考图、透明底纹和预览不透明度不会进入导出，输出仅有生成的印章，背景透明。图片和文字不上传，只在当前浏览器处理；刷新页面会清空填写及参考图。

当前生成章面图片，编号按已有信息填写。公司最终版式需要查看并确认。
