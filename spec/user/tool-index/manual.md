# 工具首页用户手册

首页默认显示清单内全部工具，每项显示名称、用途摘要、状态小字、开关和下载图标。顶栏“备忘录”左侧留有一个与顶栏按钮同高的正方形输入区域，输入内容、光标和选中效果均不可见。在该区域输入 `unlock`，再连续点击分类栏的“全部”按钮 3 次，每两次点击间隔不超过 700ms，即可显示顶栏 `csn2api` 按钮。输入后不需要在 700ms 内开始点击；刷新页面后 `csn2api` 恢复隐藏。该入口不是安全防护。

点击工具卡片右下角的下载图标会下载该工具自己的 ZIP。每个 ZIP 只包含一个工具，解压后直接打开根目录的 `index.html` 即可使用。工具页面原有的模板、Python 文件和依赖说明下载入口会保留在独立包内，不需要返回 watchdog 总目录。

顶部导航提供备忘录、下载开发文档、水族箱背景开关和白天/暗夜模式切换，不单设用户手册或 GitHub 入口。点击“下载开发文档”可保存一个合并的 Markdown 文件，文件名为 `watchdog开发者文档-YYYY-MM-DD.md`，日期为下载当天浏览器本地日期。中文正文使用 UTF-8，含系统架构、重建说明、全部开发规格和用户手册；可在 Markdown 阅读器中使用目录跳转。不需要解压，也不包含工具代码和业务模板。开发者页提供同一下载。

首页水族箱背景默认关闭；点击顶栏鱼类图标可开启或关闭动态水族箱，浏览器会记住该选择，未保存过设置时保持关闭。完成彩蛋解锁后，顶栏显示 `csn2api` 按钮，点击会在新页面打开 `https://luckymaomi.github.io/csn2api`。首页首次访问默认使用白天模式，切换后浏览器会记住选择。搜索框会按工具名称和描述筛选当前分类，“全部、重型、轻型、自动化”用于筛选当前已显示的全部工具；没有匹配结果时页面会显示空状态。

四个已弃用工具整张卡片以灰色表面显示并可正常点击，默认即出现在首页，不需要额外解锁。

工具入口状态直接维护在 `src/tool/tools-data.ts` 对应条目的 `homepageState` 字段中，只显示“已启用”“Beta 测试”“已弃用”三种状态。当前“菜鸟教程”“校对之王”和“体检排班”为 Beta 测试，“锁班乞丐”“飞行经历查询（乞丐版）”“珠海皇帝”和“自动点 OA 助手”为已弃用。
