# 工具首页用户手册

首页默认不显示彩蛋工具，每项显示名称、用途摘要、状态小字、开关和下载图标。顶栏“备忘录”左侧留有一个与顶栏按钮同高的正方形输入区域，输入内容、光标和选中效果均不可见。在该区域输入 `unlock`，再连续点击分类栏的“全部”按钮 3 次，每两次点击间隔不超过 700ms，即可让彩蛋工具直接出现在原工具网格中。输入后不需要在 700ms 内开始点击；刷新页面后恢复隐藏。该入口不是安全防护，固定工具地址仍可访问。

点击工具卡片右下角的下载图标会下载该工具自己的 ZIP。每个 ZIP 只包含一个工具，解压后直接打开根目录的 `index.html` 即可使用。工具页面原有的模板、Python 文件和依赖说明下载入口会保留在独立包内，不需要返回 watchdog 总目录。

顶部导航保留备忘录、水族箱背景开关和白天/暗夜模式切换，不再发布用户手册或 GitHub 入口。首页水族箱背景默认关闭；点击顶栏鱼类图标可开启或关闭动态水族箱，浏览器会记住该选择，未保存过设置时保持关闭。完成彩蛋解锁后，顶栏同时显示 `csn2api` 按钮，点击会在新页面打开 `https://luckymaomi.github.io/csn2api`。首页首次访问默认使用白天模式，切换后浏览器会记住选择。搜索框会按工具名称和描述筛选当前分类，“全部、重型、轻型、自动化”用于筛选当前已显示的全部工具；没有匹配结果时页面会显示空状态。

彩蛋工具包含“菜鸟教程”“换季学习”“审计之王”“航线班次统计”“实力周报”“Word 模板填充器”“PDF 工具”“PDF 加水印”“图片工具”“文本拼接助手”“人员结构统计”“运行资质比对”“英语汉语有效期比对”“国际航班资质反推”“锁班乞丐”“飞行经历查询（乞丐版）”“珠海皇帝”和“自动点 OA 助手”，显示后仍保留原分类和入口状态。四个已弃用工具整张卡片以灰色表面显示并可正常点击。

工具入口状态直接维护在 `src/tool/tools-data.ts` 对应条目的 `homepageState` 字段中，只显示“已启用”“Beta 测试”“已弃用”三种状态。当前“菜鸟教程”和“校对之王”为 Beta 测试，“锁班乞丐”“飞行经历查询（乞丐版）”“珠海皇帝”和“自动点 OA 助手”为已弃用。
