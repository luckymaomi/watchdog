# 人员结构统计用户手册

## 解决什么问题

人员结构统计在浏览器中读取人员信息原表，按技术等级和资格代码汇总教员、机长、副驾驶、等级、航线资格、报务、居住地和原单位八张统计表。可逐表复制粘贴到报告，也可导出 Excel。飞行管理人员不统计。

## 怎样操作

1. 上传包含姓名、技术信息、资格代码、原单位和检查员资格等必需表头的人员信息 Excel，选择人员信息工作表。
2. 点击“开始统计”，核对结构统计人员、机长含以上和副驾驶人数。
3. 依次查看八张表的构成合计、母数和闭环状态。等级表的教员/机长小计及占比可直接用于报告；检查员是其中项，不计入分组小计。
4. 点击表格的“复制表格”获取可粘贴的标题、表头、分组、项目、人数、占比和口径；或“导出 Excel”获取统计结果、闭环核对、规则说明、未识别数据四个 sheet。
5. 遇到“其他”技术等级、航线资格或原单位时，回原表核对，不要直接忽略。

## 操作注意事项

- 飞行管理人员、地面人员和已注册空勤总人数不统计，也不参与任何母数。
- `是否运行`不参与统计，无论是否填写，结果只按技术信息和资格代码计算。
- 技术信息为 E/F 类机长时计入机长及对应等级，C/B 类教员仍计入教员，不再设置 A 类教员等级项。
- 划转机长、副驾驶分别显示为转机型机长、副驾驶；航线资格和报务不含转机型机长，副驾驶报务不含转机型副驾驶。
- 无 RAMA/REUO/RWAS 的 E/F 类机长归入航线机长；存在这些资格时优先按资格组合归类。航线和报务报告只直接使用美、欧、西亚三类代码组合。
- 当前浏览器结果是上传时点的统计快照，不包含历史月份或本月变化；这些值需在报告中自行核对。
