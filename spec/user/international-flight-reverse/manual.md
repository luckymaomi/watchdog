# 国际航班资质反推用户手册

## 操作

1. 点击页面右上角“下载 Excel 模板”，在模板的“临期资质表”中填写员工号、姓名、资质和反推日期；资质可以直接粘贴资格描述，包含“北美”“西亚”“欧洲”或“东南亚”时会自动按对应地区查询；如需调整机场范围，可编辑“机场三字代码”表。
2. 上传航班明细表和填写后的临期资质表。航班表需有“员工号、日期、离场、到达”，临期资质表需有“员工号、姓名、资质、反推日期”。
3. 检查地区机场三字码。临期资质表包含“机场三字代码”表时会自动读取；也可以在页面文本框中编辑，每行格式为 `地区=LAX,JFK,ORD`。
4. 设置近期航班数。默认导出每个员工/地区最近 3 个去重后的航段，可改为其他正整数。
5. 根据业务口径调整离场/到达匹配、资质年限和重叠月数；默认年限 1、重叠 0 个月，建议有效期固定取目标月月底。
6. 点击“开始分析”，查看摘要、机场近期航班明细和数据问题。
7. 点击“导出 Excel”，下载包含汇总、近期明细、机场近期航班、机场配置和数据问题的复核文件；汇总和明细会同时保留原始“资质”与归一后的“地区”，机场近期航班按每个人/机场分别取设定数量。

## 口径说明

- 反推日期当天包含在检索范围内，日期之后的航班不会命中。
- 同一航班的起飞、巡航、着陆阶段会合并为一个航段；同航班号同日的不同离场/到达路线分别保留。
- 最近航班日期只用于资质监控人工核对，不自动判定英语通信、单飞等资质是否有效。
- 建议有效期按“最近航班月份加年限，再按重叠月数前移，取目标月月底”计算。默认加一年、不提前月；例如最近航班为 `2026-11-06`，建议有效期为 `2027-11-30`，同年 11 月内其他航班也按到 `2027-11-30` 有效；2 月会自动取 28 日或闰年的 29 日。最终办理仍需依据现行手册和飞行门户记录。
- 数据问题表中的无效行、重复任务和未配置地区需要回原 Excel 人工确认。
- 同一员工同一地区可以有多条不同资质；只有员工号、资质和反推日期完全相同的重复行才会跳过。
