# 实力周报用户手册

## 解决什么问题

实力周报把多期飞行实力表整理成三类周报图：当前教员/机长/副驾驶结构、当前北美/欧洲带队人数，以及多期人员指标变化。全部处理在本地浏览器完成，原始 Excel 不会被修改或上传。

## 怎样操作

1. 点击“选择实力表”一次多选文件，或把 `.xlsx`、`.xls` 直接拖入上传区。后续可继续追加文件。
2. 检查文件卡片中的日期、运行人数和排除人数。解析失败的文件会单独列出原因，不影响其他文件。
3. 按时间先后拖动文件卡片；也可以点击上下箭头调整。排序最后一份标记为“当前”，上方摘要、饼图和带队柱状图都取这份文件。
4. 在“多期变化”中切换柱状图或折线图。导入两份以上文件后，页面默认只勾选发生变化的指标，也可点击“全选”或自行复选。
5. 图表确认后，点击“导出周报 PNG”生成一张报告图片，或点击“导出统计 Excel”获取快照统计与相邻变化。每个图右上角的保存按钮还可单独导出该图。

## 统计口径

- 工具通过表头识别数据 sheet，需要同时存在“技术信息”“是否运行”“RAMA”“REUO”。sheet 可以改名，列顺序可以变化。
- 只有“是否运行”为“是”的人员进入统计。
- 技术信息包含教员、机长或副驾驶文字时进入对应分类；未识别人员仍计入运行人数，页面会给出提示，需回原表核对。
- RAMA 表示北美带队，REUO 表示欧洲带队。样表中的数字 `1` 会被识别为有资格，空白不计入。
- 文件名含八位日期时自动显示成 `YYYY-MM-DD`；没有可识别日期时使用原文件名作为横轴标签。

## 使用注意事项

- 文件顺序直接影响趋势图和 Excel 的相邻变化，导出前应确认“当前”标记位于正确文件。
- 页面不限制文件数量，但一次导入大量大文件会占用浏览器内存；如浏览器响应变慢，可减少文件后分批处理。
- 默认勾选只反映指标数值是否变化，不代表变化好坏；最终周报口径仍应结合原始实力表复核。
- 如果运行人数不等于饼图三类之和，先查看技术信息未识别提示。
